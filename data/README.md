# Données

Le notebook télécharge automatiquement le fichier Excel UCI à sa première exécution.
Ce dossier conserve les données localement ; les fichiers de données ne sont pas versionnés.

Source : [Default of Credit Card Clients — UCI](https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients),
Yeh (2009), DOI [10.24432/C55S3H](https://doi.org/10.24432/C55S3H).

30 000 observations, 23 variables explicatives, un identifiant et une cible.
Population : clients d’une banque à Taïwan ; historique d’avril à septembre 2005.
Les montants sont exprimés en nouveaux dollars taïwanais (NT$).
La cible indique le défaut de paiement le mois suivant.
